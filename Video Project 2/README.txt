STUDENT REWARD SYSTEM — CLIPCHAMP IMPORT PACK

This folder contains a presentation-ready set of images, voice-over clips, and
captions for assembling the video in Clipchamp. The Clipchamp editor was not
accessible during preparation, so no Clipchamp project file or finished MP4 is
included.

IMPORT AND ASSEMBLE

1. In Clipchamp, create or open the project named "Video Project 2".
2. Import all files in Images and Audio.
3. Place the numbered PNG images on the video track in order, from 01 to 10.
4. Place each numbered WAV clip beneath its matching image. Extend each image
   to cover its narration clip; the matching subtitle is in Captions.srt.
5. Import Captions.srt if your Clipchamp version supports subtitle import.
   Otherwise, use it as the transcript when adding captions.
6. Preview the sequence, adjust image durations and transitions to taste, then
   export from Clipchamp.
